## 三、问题汇总与修复建议

### 3.1 高优先级问题

#### 问题 1：MiniMax 流式响应参数错误
- **位置**：`test_backend_module.py` M3 测试
- **现象**：`post() got an unexpected keyword argument 'stream'`
- **原因**：httpx 库的 stream 参数使用方式不正确
- **修复建议**：
  ```python
  # 错误写法
  response = httpx.post(url, stream=True)

  # 正确写法
  with httpx.stream("POST", url) as response:
      for line in response.iter_lines():
          pass
  ```

#### 问题 2：SQL 验证返回 None
- **位置**：`sql_generator.py` validate_sql 方法
- **现象**：无效 SQL 验证返回 `(False, None)` 而非错误信息
- **原因**：某些情况下 error 变量未赋值
- **修复建议**：确保所有分支都返回错误信息

#### 问题 3：前端表格数据展示缺少状态管理
- **位置**：`frontend/src/store/` 缺少 `queryResultStore`
- **现象**：查询结果无法以表格形式展示
- **修复建议**：创建 `queryResultStore.js` 存储查询结果数据

#### 问题 4：Schema 注册接口参数问题
- **位置**：`query.py` register_schema 接口
- **现象**：返回 422 Unprocessable Entity
- **原因**：接口参数传递方式不正确（使用 params 而非 body）
- **修复建议**：
  ```python
  # 当前错误写法
  async def register_schema(table_name: str, columns: List[Dict], session_id: str = None)

  # 建议改为 Pydantic 模型
  class SchemaRegisterRequest(BaseModel):
      table_name: str
      columns: List[Dict]
      session_id: Optional[str] = None
  ```

### 3.2 中优先级问题

#### 问题 5：LangChain ForwardRef 兼容性
- **位置**：`sql_generator.py` LangChain 组件
- **现象**：`ForwardRef._evaluate() missing recursive_guard`
- **原因**：LangChain 版本与 Python typing 不兼容
- **修复建议**：升级 langchain 或调整导入顺序

#### 问题 6：数据库结果格式化不一致
- **位置**：`query_executor.execute_query` 返回格式
- **现象**：有时返回列表，有时返回其他格式
- **修复建议**：统一返回格式为 `List[Dict]`

### 3.3 低优先级问题

#### 问题 7：接口响应时间较长
- **位置**：多个 POST 接口
- **现象**：平均响应时间 2-3 秒
- **建议**：考虑添加超时限制和加载状态提示
